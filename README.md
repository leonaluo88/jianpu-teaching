# 简谱教学台

调式教学、节奏教学、视唱练耳三合一的简谱教学网页。纯静态网页，无需安装，离线也能用。

- 在线使用：https://leonaluo88.github.io/jianpu-teaching/
- 使用说明：https://leonaluo88.github.io/jianpu-teaching/files/guide.html

## 文件结构

- `index.html`：入口页（三个教学页面的导航）
- `files/index.html`：调式教学
- `files/rhythm.html`：节奏教学
- `files/ear-training.html`：视唱练耳
- `files/guide.html`：老师版使用说明
- `files/app.js`、`files/styles.css`：三页共享的逻辑与样式
- `files/piano-samples.js`：调式教学钢琴采样（Salamander Grand Piano by Alexander Holm, CC BY 3.0）
- `files/assets/fonts/BravuraText.woff2`：音符图形字体
