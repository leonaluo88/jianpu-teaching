开始之前

在线版：直接打开网址即可，手机、电脑都能用，建议收藏。

离线版（压缩包）：

  1. 先解压压缩包（直接在压缩包里双击可能打不开）。
  2. 打开解压出来的文件夹，双击 双击打开-简谱教学台.html。
  3. 用 Chrome、Edge 或 Safari 打开即可，不需要联网。

文件夹里的 files 是网页本身，不用打开，也不要移动或改名；整个文件夹可以一起复制到 U 盘或别的电脑。

页面顶部（三页都有）

  • 页面切换：调式教学 / 节奏教学 / 视唱练耳 / 爵士和弦。
  • 拍号：例如 4 / 4、3 / 4。调式、节奏、视唱练耳三页共用，改一处，其他页同步（爵士和弦页不用拍号）。
  • 1 =：调号，只在调式教学页出现，可输入 C D #F bE 等；降号写在前面（bE）或后面（Eb）都可以。输错时保留原来的调。
  • 恢复默认：所有页面的设置一起回到初始状态（见最下方“默认值”）。
  • ?：打开本说明。

设置会自动记住，下次打开还是上次的状态。

调式教学 打开

把 1–7、Do Re Mi Fa So La Si 和钢琴键对应起来，适合示范调式与移调。

怎么用

  1. 在顶部 1 = 输入调号，例如 G，钢琴上的 1–7 会自动移到新调的位置（带动画）。
  2. 钢琴上方的 显示几个八度 可调 2–7 个八度。
  3. 勾选 点键盘发声 后，点钢琴上任意键会发出声音。
  4. 下方 随机抽音练习：点 换一个音级 随机出一个数字，让学生唱，旁边显示唱名和当前调里的音名。
显示细节
  • 键盘是完整 88 键，按八度数自动放大到中间区域；以 4 (Fa) 为视觉中心展开。
  • 钢琴左侧两行标注：音级（Scale Degree）、唱名（Solfege）；中央 C 上方标注“音名（Note Name）”，说明字母一行是音名。
  • 黑键标两行：上面是 ♯ 名称（如 ♯C），下面是 ♭ 名称（如 ♭D）。
  • 键盘配色与爵士和弦页一致：当前调的音阶音为玫瑰色，主音（1）颜色更深。
  • 上方圆形数字按白键间距等距排列；Do 的连线始终垂直，落在黑键上的音用斜线指向实际键位。
  • 调式教学的点键盘发声和爵士和弦页使用真钢琴录音采样：Salamander Grand Piano（Alexander Holm，CC BY 3.0 许可）。
  • 换调动画分两步：先移动连线下端到新键位，再平移、缩放键盘。

节奏教学 打开

用音符拼出几小节节奏，配合节拍器和“V 形”动画演示每拍里的时值。

怎么用

  1. 设置 BPM（速度）和 展示几个小节（1–8）。
  2. 选择编辑范围：全局（按顺序从头往后填）或 第 n 小节（从该小节开始填）。也可以直接点下方某个小节的 V 形卡片。
  3. 点音符卡片（全音符、二分、四分……）把它加进去。
  4. 在“已用”区：点一下删除某个音符，拖动可调整顺序。
  5. 点 播放节拍器，节拍器响起，V 形描线随节奏推进，整段循环播放。
规则与显示细节
  • 每小节的 V 数量 = 拍号的分子（4/4 显示 4 个 V，3/4 显示 3 个），不会因为细分音符而增加；一拍里的细分用不同颜色表示，每个音符起点在 V 上打点。
  • 音符可以跨小节：例如最后一拍放二分音符，会自然延续到下一小节开头。剩余空间不够放的音符会变灰不可点。
  • 清空 / 补满只作用于当前编辑范围；补满用当前拍号的一拍来填。
  • V 形区可切换“一行四个 / 一行两个”小节，默认一行四个。
  • “已用”区可 收起，也可 隐藏名称（只留音符图形和拍数，投屏时更干净）。
  • 节拍器声音按 BPM 实时生成，不依赖音频文件。

视唱练耳 打开

单音、双音、和弦、随机旋律与节奏的听辨练习。本页固定按 1=C 出题。

怎么用

  1. 选题型：听单音 听双音 听和弦 随机旋律。
  2. 点 播放：先响基准音 A3 (la)，再响题目。可反复播放。
  3. 学生作答后点 显示答案；点 下一题 换题。

各题型的开关

题型可用开关
听单音 / 听双音打开黑键
听和弦自然音三和弦（开：只出自然音三和弦；关：随机 3 个音，此时“打开黑键”生效）
随机旋律BPM、出题小节数、最小拆分、打开随机节奏、打开黑键、仅听节奏
随机旋律的出题规则
  • 随机旋律和仅听节奏都会先给 1 小节预备拍。
  • 打开随机节奏 关：按拍均分出旋律；开：按拍号和“最小拆分”生成随机节奏。
  • 最小拆分 限制节奏最细到几分音符，只有打开随机节奏或仅听节奏时才可用。附点音符同样受限：最小拆分到八分音符时才会出现附点四分；到十六分音符时才会出现附点八分。
  • 仅听节奏：所有音都用 A3，并垫上节拍器，只练节奏；开启时会自动关闭并锁定“打开随机节奏”和“打开黑键”。
  • 答案按小节显示：左边是音符卡片，右边是对应的简谱写法（数字、附点、增时线、减时线）。仅听节奏模式下数字显示为 x。

爵士和弦 打开

C 调上常用的爵士和弦，例如 Fmaj7（Fa La Do Mi）、Fdim7（Fa ♭La Si Re）。分听辨和测验两个模块，顶部可以切换。

听辨

  1. 所有和弦按四组列出：自然七和弦、六和弦与九和弦、属七变化与副属和弦、借用与减七，共 23 个。
  2. 点任意和弦卡片，就会弹出这个和弦，上方键盘同时亮出按下的键。
  3. 勾选 琶音模式：从低到高快速逐个弹出；不勾选：所有音一起弹出。

测验（盲听）

  1. 勾选 出题范围（可多选，默认只考自然七和弦）。
  2. 点 播放题目，听完在心里说出是哪个和弦；可以反复点来重听。
  3. 点 显示答案 查看和弦名、唱名、简谱数字和音名，键盘上也会亮出来。
  4. 可以点 我答对了 / 没答对 自己记分；点 下一题 换题并直接播放。
  5. 测验同样有 琶音模式，和听辨的开关互不影响。勾选 先弹 C 大三和弦作参考 后，每次出题前先弹一下 C 大三和弦，帮助找调。
卡片上各行的意思
  • 第一行：和弦名称，如 Fmaj7。
  • 第二行：级数写法，如 IVmaj7 表示 C 调的四级大七和弦。
  • 第三、四行：实际弹出的音，从低到高，分别用唱名和简谱数字写；♭ / ♯ 表示降半音 / 升半音。
  • 第五行：音名。部分和弦下面还有一行补充说明（比如省略了哪个音、通常接到哪个和弦）。
  • 每个和弦都用低音弹根音、上方弹和弦音的方式演奏；最低音在 F2 到 E3 之间。

默认值

点 恢复默认 后：

  • 拍号 4/4，调号 1=C
  • 调式教学：显示 2 个八度，点键盘发声关闭
  • 节奏教学：BPM 120，展示 2 个小节
  • 视唱练耳：BPM 120，出题 2 小节，最小拆分到八分音符；打开随机节奏、打开黑键、仅听节奏都不勾选
  • 爵士和弦：打开听辨模块；琶音模式、C 大三和弦参考都不勾选；测验只考自然七和弦；记分清零

没有声音？

  • 检查电脑音量和浏览器标签页是否被静音。
  • 浏览器要求先点击页面才能发声：先点一下页面上的按钮再试。
